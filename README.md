## С чего начать запрос в боте

Для номера используйте международный формат с кодом страны; для email — полное написание без пробелов; для username — точный ник и его варианты; для Telegram ID — числовой ID, если он известен законным способом. Фотографию лучше загружать без рамок, подписей и сильного сжатия. ФИО полезно дополнять городом, примерным возрастом или прежней фамилией, иначе однофамильцев будет слишком много.

Возможный ответ может объединять телефоны, email, ники, открытые профили, фотографии, упоминания сервисов, регион или открыто опубликованный адрес. Какие именно поля появятся, заранее сказать нельзя.
